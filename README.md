# capulus-ios

SwiftUI-App „Homeserver Dashboard“ für iPhone und iPad: Alarme, Host-Metriken und Dienststatus des Capulus-Homelabs sowie Helligkeit und Wake/Shutdown der Server. Das Backend ist `carplay-api` in [capulus-core](https://github.com/pkr-lab/capulus-core).

## Quickstart

```bash
brew install xcodegen
xcodegen generate
open HomeserverDashboard.xcodeproj
```

Danach in Xcode das Team einstellen und ⌘R. Beim ersten Start den API-Token in den Einstellungen hinterlegen.
